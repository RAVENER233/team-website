Frequently Asked Questions

Learn more about DynamoRaven, our team and the projects we build.

What does the name DynamoRaven mean?

Dynamo stands for energy and drive, while Raven represents creativity and intelligence. Together, the name reflects how we bring energy and creative thinking into every project we build as a team.

What is our team aiming to achieve?

Our goal is to improve our technical skills, solve practical problems and gain experience by developing useful web applications.

How do we collaborate as a two-person team?

We divide tasks between the two of us, share ideas and check each other's work along the way. GitHub keeps our code in one place, so we can both work on the project without stepping on each other's toes.

Why do we use HTML, CSS and JavaScript?

HTML gives our pages structure and meaning, CSS handles the design and layout, and JavaScript makes the site interactive. Together they let us build websites that are clean, responsive and easy to use.

How do we use Git and GitHub in our workflow?

We use Git to track changes to our code and GitHub to store it online and share it with each other. This lets us work on different parts of the project at the same time and merge our work safely.

Can we build a website for someone else?

Yes. We are always open to building websites for individuals or small businesses. Feel free to reach out through our contact page and tell us what you have in mind.
